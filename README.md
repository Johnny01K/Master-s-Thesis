#Master-s-Thesis
#Utilizing the YOLO Algorithm for car image recognition under rainy weather conditions

**Master's Thesis Research Project | 2025**

##Overview

This project investigates the performance of the YOLOv8 object detection model in detecting cars under different rainy weather conditions.

The research was conducted as part of a Master's degree in Information Technology at the University of Novi Sad, Technical Faculty “Mihajlo Pupin”, Serbia.

##Objectives

- Examine car detection under different weather conditions.
- Analyse detection confidence scores and the number of detected vehicles.
- Compare experimental results across different image groups.
- Investigate detection limitations, including missed detections and false positives.

##Tools and Technologies

- Python
- YOLOv8
- Google Colab
- OpenCV
- Pandas
- Matplotlib and Seaborn
